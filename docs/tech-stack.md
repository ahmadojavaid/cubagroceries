## Architecture Decisions

**Why Filament over ShadCN?**
Filament is Laravel-native, Livewire-powered, and ships with everything needed for an admin panel. ShadCN would require a separate React frontend, adding CORS complexity, a separate build process, and an extra deployment. Filament keeps admin logic in one codebase with full-width layouts configured via panel provider.

**Why PostgreSQL over MySQL?**
Already set up with PgAdmin 4 on the development machine. PostgreSQL offers better JSON support, more robust constraint handling, and better performance for complex queries. The original system used MySQL — we're upgrading.

**Why Riverpod over Bloc?**
Riverpod is compile-safe, has less boilerplate than Bloc, handles dependency injection naturally, and pairs well with the feature-first architecture. ProKit screens are UI-only and don't enforce a state management pattern, so Riverpod integrates cleanly.

**Why copy ProKit screens instead of using as dependency?**
ProKit is a commercial UI kit, not a package. Screens are extracted, adapted to our data models and API, and embedded directly. This means the kit can be deleted after extraction, no license issues at runtime, and we have full control to modify layouts.
